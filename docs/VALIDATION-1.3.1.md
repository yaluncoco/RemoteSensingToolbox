# 1.3.1 验证记录

版本：`v1.3.1`。验证日期：2026-10-21，本机 Windows x64，Python 3.10.21。

## 滚轮交互

- 75 项回归测试通过，其中 17 项覆盖点云可视化的数据读取、颜色、界面交互和任务退出。
- 在实际预测分析页面，通过 Qt 窗口事件分发滚轮事件，验证控件未获得焦点和已有焦点时的上下滚动。
- 覆盖数据排列、着色方式、RGB 范围、分隔符、坐标列、标签列、RGB 列号和表头行数；滚轮操作后整组格式参数保持不变，页面滚动条在可滚动方向继续移动。
- 数字输入框的文本区域也能将滚轮传递给页面；不会把滚轮变成数值增减。
- 验证点击展开下拉列表并选择 XYZ + Label、键盘切换格式、手动输入标签列号；原有最小窗口无横向溢出的检查通过。

## 打包检查

- 源码通过 19 项自检，包括原生 OpenGL。
- 打包后的 Windows 程序通过 18 项自检，运行时清理外部 Python、Conda、GIS、Qt 路径依赖。
- Inno Setup 安装包编译成功；便携 ZIP 的 1908 个文件通过 CRC 检查。
- 两个发行文件的大小和 SHA-256 已核对，机器可读报告为 `validation-1.3.1.json`。

本次修改仅涉及可视化格式区的滚轮交互，安装和更新逻辑未更改；此前的实际升级与重启验证见 [1.3.0 验证记录](VALIDATION-1.3.0.md)。
