# 1.1.1 验证记录

应用源代码标签：`v1.1.1`。Windows x64，Python 3.10.20。

- 41 项回归测试通过，包括新版本检测、红点、缓存、失败重试、重复点击、超时后迟到结果和退出处理。
- Windows 原生界面及 100%、125%、150%、200% 模拟缩放验证通过；采用系统实际比例，不将 150% 取整为 200%。
- 960×600 默认窗口完整显示 8 个工具；760×520、640×420 和 1100×650 下自动切换列数，未出现横向溢出或简介裁切。
- 分类、组合关键词搜索、空结果和更新红点显示正常；升级首次重置窗口尺寸、后续恢复自定义尺寸及分类均通过。
- 便携包不再包含内置使用说明文件；安装配置已移除说明快捷方式，并在升级时清理旧版说明文件和快捷方式。
- 打包后的程序通过 16 项离线自检，包括 HTTPS 运行库。
- 安装到包含中文和空格的目录后，17 项自检通过，包括原生 OpenGL 三维渲染。
- 自检进程从安装目录以外启动，PATH 仅保留 Windows 系统目录，并清除了 Python、Conda、GIS 和 Qt 的外部路径变量。
- 当前用户静默安装、开始菜单快捷方式、原生 Windows 主窗口启动与正常退出均通过。
- 静默卸载通过，测试安装文件、卸载注册和开始菜单入口已清理。
- 便携 ZIP 的 1905 个文件通过 CRC 校验，安装包和 ZIP 的 SHA-256 与清单一致。

验证使用本机 Windows 环境，不是全新虚拟机测试。仓库当前为私有，客户端匿名获取更新信息会返回 404；该限制不影响本地工具和手动下载安装。
