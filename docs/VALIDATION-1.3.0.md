## 隔离升级实测

1. 使用独立 AppId、独立开始菜单组和中文目录安装 v1.2.0。
2. 实际运行更新界面，经下载、SHA-256 校验和安装前再次校验后启动安装程序。
3. 模拟旧程序持有可执行文件的写入/删除锁，并在窗口关闭后保留进程 3 秒；确认进程退出前旧文件没有被替换，安装器日志记录等待旧进程。
4. 旧进程退出后完成 v1.2.0 → v1.3.0 升级，注册版本更新为 1.3.0，新版自动启动并正常退出。
5. 升级后的程序在清理外部 Python、Conda、GIS、Qt 路径的环境下，通过 19 项自检，包括原生 OpenGL。
6. 卸载测试安装，确认测试注册与菜单组已清理，原有正式安装的版本、目录和卸载注册保持不变。

隔离安装包使用与正式版相同的应用文件和安装逻辑，仅替换测试 AppId/显示名称并关闭压缩。为稳定复现下载与安装，下载传输在测试中替换为本地 HTTP 服务；生产代码仅接受 HTTPS。此验证在本机完成，未使用全新虚拟机。
