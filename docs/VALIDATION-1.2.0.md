# 1.2.0 验证记录

源码版本：`v1.2.0`。本机 Windows x64，Python 3.10.21；验证日期：2026-10-15。

- 56 项回归测试通过，其中 15 项覆盖新点云格式、列位置、着色、预览与界面交互。
- 覆盖三列 XYZ、四列 XYZ + Label、六列 XYZ + RGB、七列标签、十列法向量及自定义列顺序。
- 覆盖单点、中文路径、UTF-8 BOM、空格/Tab/逗号/分号、表头、注释、空文件、错误列数、非整数标签、NaN/Inf、颜色越界和完整文件后部的错误。
- 标签原编号、未配置类别的灰色、RGB 统一范围缩放、无效颜色映射提示通过验证。
- 后台失败提示、重试按钮恢复、先关闭工具再结束渲染、合并结果重置读取设置通过验证。
- 原生 Windows 界面在 100%、150%、200% 模拟缩放下验证；1120×760 和最小 840×580 窗口未发生横向溢出，新增说明文字无裁切。自定义参数与读取设置按需展开，长页面纵向滚动。
- 5 种格式/着色组合各渲染 2,000 个点，真实 OpenGL 窗口正常关闭并生成非空截图；中文 PNG/JPEG 保存及失败时保留旧文件通过验证。
- 源码 18 项自检通过；打包程序 17 项离线自检通过，额外开启原生 OpenGL 后 18 项通过，包含新格式 CSV 标签读取。
- 便携程序从发行目录以外启动，PATH 仅保留 Windows 系统路径，并移除外部 Python、Conda、GIS 和 Qt 路径变量；Windows 主窗口启动与正常退出通过。
- 便携 ZIP 的 1908 个文件通过 CRC 检查，安装包和 ZIP 的 SHA-256 与清单一致。

本次为本机测试，未使用全新虚拟机。机器已有用户安装，未执行安装/卸载覆盖测试，保留现有安装与开始菜单入口；发行程序已完成独立运行验证。安装器沿用既有配置，仅更新版本。
