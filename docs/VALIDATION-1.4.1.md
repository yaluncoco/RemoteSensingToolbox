# 1.4.1 验证记录

验证日期：2026-11-07，Windows x64，Python 3.12.7。

## 原因和修复

v1.4.0 安装包仅收集 Qt5Agg 和 Agg 后端，遗漏 `matplotlib.backends.backend_svg`。用户任务已经完成 CSF / TreeIso 和编号，在写入 SVG 总览图时失败，因此没有继续完整点云与逐树 LAZ 导出。

此前四份真实数据跑的是源码环境；旧安装版自检只覆盖窗口、文件读写、插件检查和 BIN 转换，没有跑到 SVG 绘图和完整导出。这是发布验证缺口。

- 明确打包 SVG 后端；任务开始前实际试写 PNG / SVG。
- 三张图成功后才写入分割完成记录，复用旧缓存时补齐缺失图片，保留原编号。
- 离线自检使用固定分组夹具，实际执行分析、两张 PNG、一张 SVG、完整标注和逐树导出，并读回核验。
- 配置 CloudCompare 的自检通过实际单木分割窗口的开始按钮和 QThread 运行真实引擎流程，检查完成状态和结果按钮。

## 验证结果

- 100 项回归测试全部通过，无跳过；包含真实插件与 BIN 集成，以及绘图失败、提前检查、旧缓存恢复回归。
- 源码 24 项自检、冻结发行版 24 项自检全部通过。均包括真实引擎的六树合成数据完整窗口流程。
- 使用正式安装包安装到本机后，全部 2487 个应用载荷文件与构建目录 SHA-256 相同；安装版通过 26 项自检，包含原生 OpenGL 和真实用户数据。
- 安装版自检清理外部 Python、Conda、GIS、Qt 环境路径。安装程序未卸载现有用户应用；此补丁未重跑卸载验证。
- 原生 Windows Qt 模式另通过 21 项程序自检，单木分割界面的中文文字和控件截图显示正常；离屏插件截图缺少文字不作为界面显示依据。
