# 1.4.0 验证记录

版本：`v1.4.0`。验证日期：2026-11-06，Windows x64，Python 3.12.7。

## 功能与数据验证

- 96 项回归测试通过，覆盖 CloudCompare 路径持久化、插件检查、取消、任务隔离、BIN 内容识别、属性保留、逐树导出，以及既有影像、点云和更新功能。
- 真实 CloudCompare 完成合成林地流程，并将扩展名为 `.laz` 的真实 BIN 自动转换和逐属性核验。
- 四份真实人工林数据共 56,924,569 点完成处理，输出 1,403 个候选和 159 个重点复核标记；原文件哈希保持一致。
- 原始点属性、点序、体素标签和每个独立单木文件均已校验。候选需要人工复核，未跨文件去重，也未计算基于人工真值的识别精度；详细记录见 [单木分割验证](VALIDATION-TREE-SEGMENTATION.md)。

## 安装与打包验证

- 源码通过 22 项自检，正式便携构建通过 20 项离线自检。
- 安装到中文和空格路径后，通过 23 项自检，包含外部 CloudCompare 插件、误写扩展名的 BIN 转换和原生 OpenGL。
- 自检清理外部 Python、Conda、GIS 和 Qt 路径依赖；当前用户静默安装、开始菜单快捷方式、原生主窗口启动与退出、静默卸载均通过。
- 便携 ZIP 的 2487 个文件通过 CRC 检查，安装包与便携包 SHA-256 与清单一致。
- 验证在本机 Windows 环境完成，未使用全新虚拟机。CloudCompare 及 CSF / TreeIso 插件需用户另行安装。
