# 遥感与点云综合工具箱

选择左侧分类或输入关键词找到工具，点击“打开”或双击卡片开始使用。
按 **Ctrl+K** 可直接搜索，例如输入 `RGB TIF`。关闭工具窗口会释放该窗口占用的资源。

主窗口默认 960×600，卡片根据可用宽度自动排列为一至三列；小窗口可纵向滚动查看其余工具。窗口尺寸和上次选择的分类会自动保存。使用指南统一在 GitHub 本页和 [完整手册](../遥感点云工具箱_使用与维护手册.md) 查看。

## 检查更新

左下角的循环箭头是检查更新入口。程序启动后会自动在后台检查，持续运行期间每 6 小时再检查一次；有新版时，图标右上角显示红点。点击图标可查看版本和更新说明，再点击“前往下载”打开发布页面，选择安装包或便携版。

红点会保留到安装新版后；关闭更新窗口不会清除提醒。检查失败不影响工具使用，可在更新窗口点击“重新检查”。

## 图像处理

- **图像切片**：选择影像与同名标签，设置切片尺寸和有效像素比例。边缘可补齐或跳过，图像与标签同步输出。
- **图像与标签可视化**：查看遥感影像和类别标签，按自定义颜色显示。大幅 TIFF 使用缩略预览。
- **RGB 颜色提取**：载入图例截图或粘贴剪贴板图像，提取色块并导出 CSV、JSON 或颜色字典。
- **TIF 转 RGB**：选择 RGB 波段，输出 PNG、JPG 或带地理参考的 RGB TIFF。单波段影像自动转为灰度 RGB。
- **TIF 矢量栅格化**：将 GPKG 标注映射至参考 TIFF，生成类别 ID、RGB 和调色板三份标签文件。调色板最多支持 255 个前景类别。
- **SHP 标签转 TIF**：按属性字段栅格化，支持批量同名配对和自定义类别值；较大的类别值自动使用 16/32 位整数。

TIF 转 RGB 使用分块读写。百分位拉伸在大图上使用最多约 100 万像素的全图采样；填 `0` 则逐块统计精确的最小/最大值。无效像素不参与拉伸，RGB TIFF 使用独立掩膜区分无效区域和有效黑色像素。PNG/JPG 不保留地理参考。

## 点云处理

工作台提供预览、统计/半径去噪、格式转换、ScanNet 数据整理、NPY 信息查看、预测标签合并及 TXT 下采样。

- **随机采样**：快速随机选点。
- **均匀采样**：按文件行序，覆盖从首行到末行。
- **最远点采样**：改善空间覆盖，大文件及较大的目标点数会耗时较长。
- **体素网格**：每个体素选择最靠近中心的原始点，完整保留该点的 RGB、类别和其他特征，不改变颜色数值范围。

TXT 下采样请使用独立的输出文件或输出目录。批量输出目录可以在输入目录内，程序会跳过已有的输出子目录。

## 数据集

VOC 制作会按固定随机种子划分训练/验证集。影像与标签使用相同文件名（可有不同扩展名），避免在输入目录内放置同名的不同格式影像。8/16 位整数标签及调色板标签会保留类别值；RGB 标签沿用灰度转换规则，训练前请确认其灰度值就是所需类别 ID。

## 取消与退出

TIF 转 RGB 可点击“取消转换”。其他正在处理的工具在关闭窗口时会询问是否停止任务。
确认后，窗口等待当前处理安全结束再关闭，期间界面仍可响应。大文件编码或点云库内部操作可能需要一段时间。
TIF 转 RGB、SHP/GPKG 栅格化及 TXT 下采样会先写临时文件，成功后再替换输出。已成功完成的批量文件会保留。

## 安装与使用

Windows 10/11 64 位安装包包含 Python 和所需运行库，安装后无需另装 Conda 或 Python。
便携版请完整解压后运行 `RemoteSensingToolbox.exe`，不要单独移动 exe。
安装版支持开始菜单入口和系统“已安装的应用”卸载。程序不会在安装目录保存用户数据。
